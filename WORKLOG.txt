[ 주요 파일 ]
- app.py            : Streamlit 메인 앱 (7개 기능 모드)
- rag.py            : PDF 기반 인용 단락 작성 (BM25)
- scholar.py        : Semantic Scholar 문헌 검색
- data_analyzer.py  : 데이터 분석
- style_analyzer.py : 글쓰기 스타일 분석
- sjr_data.py       : SJR(저널 등급) 데이터
- export.py         : 내보내기 (docx 등)
- progress.md       : 기존 진행 메모(참고용)

[ 기능 모드 ]
1. 자유 질문        - Claude 자유 대화
2. 단락 작성(RAG)   - 업로드 PDF 기반 인용 단락
3. 문헌 추천        - Semantic Scholar + SSCI 우선 + SJR 등급
4. PDF 분석         - 논문 PDF 요약/분석
5. 논문 구조 설계   - 주제 → 구조 제안
6. 글쓰기 교정      - 학술체 변환
7. 참고문헌 변환    - APA 등 인용 형식
